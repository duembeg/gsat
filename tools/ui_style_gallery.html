gsat PySide — control style options

Visual gallery only (HTML/CSS). Pick directions for checkboxes, spin steppers, and primary/OK buttons. Tokens match the workbench cool neutrals + accent blue. Not pixel-linked to Qt QSS yet — this is for choosing.

What the app was doing (before fix): checkbox = solid blue box with no checkmark at all (QSS filled the indicator and Fusion does not paint a tick on a fully restyled indicator — the HTML “A” card below used to wrongly show a white tick). OK = solid blue primary; spin arrows often empty.
App fixes applied: checkbox → C; spin → E (accent steppers); primary OK → C (soft blue).

Checkbox

A · Solid blue, no tick old bug

What your screenshot showed: QSS solid fill, no image → empty blue square. Not intentional design.

B · Outline + blue check

White/light box, blue tick only. Clear without painting the whole control accent.

C · Soft blue tint + check now in app

Middle ground: light blue wash + accent tick. Nice with hover language.

D · Green success tick

Reserves blue for actions; green = “enabled/on”. Can feel more machine/HMI.

E · Minimal dark check

Almost monochrome. Very quiet; least “branded”.

Spin up / down (step size, feed, spindle…)

A · Empty steppers ≈ current pain

What you feel now: hit targets exist, arrows invisible or missing under Fusion + our QSS.

B · Stacked ▲ ▼ (visible)

Classic Qt layout, but with real glyphs and light gray strip. Compact for dense panels.

C · Flat stacked arrows

No gray strip; arrows only. Closest to “pad-like” quiet chrome.

D · Side − / +

wx-ish and very obvious. Wider; great for jog feed/spindle, a bit big for tables.

E · Accent steppers now in app

Blue-tinted buttons. Clear affordance; slightly louder.

Primary / OK buttons

A · Solid blue OK old

Strong default. Fine for rare dialogs; feels heavy if every confirm is a blue brick.

B · Outline accent OK

Same weight language as form buttons; OK stands out by border/color, not a full fill.

C · Soft blue OK now in app

Tinted primary — between solid and outline. Friendly, modern.

D · Both outlined; OK bold text

Most neutral. Hierarchy only by weight — may be too subtle for settings save.

E · Keep solid for primary only

Compromise: solid only for rare high-intent actions (Save / Connect), not every OK.

How to use: open this file in a browser (tools/ui_style_gallery.html). Tell me your picks, e.g. “Checkbox B, Spin B or D, OK C” — then we map them into theme.py QSS (and spin indicators if needed).

There isn’t a single public “Qt style catalog” link that matches our tokens; this gallery is the decision surface. Qt Fusion + custom QSS is what we control.
